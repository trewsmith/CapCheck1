# CapCheck

CapCheck is an Android financial education app built as part of the Google Play × All Star Code Technology Entrepreneurship Incubator 2026.

CapCheck helps new investors understand financial metrics by providing context directly alongside financial data.

## Features

* Plain-language explanations of financial metrics
* Inline explanations for P/E ratios, margins, and growth rates
* Peer comparisons by sector and market cap
* AI-generated summaries of earnings call highlights
* Personalized learning paths for new investors

## Built With

* Android
* AI
* Financial market data APIs
